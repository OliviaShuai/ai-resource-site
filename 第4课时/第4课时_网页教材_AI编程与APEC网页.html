网页三件套：HTML、CSS、JavaScript23 分钟 · 结构 · 样式 · 交互

🦴
HTML = 骨架

决定页面上“有什么”：标题、段落、图片、列表、链接。就像盖房子的砖和梁。

🎨
CSS = 皮肤

决定“长什么样”：颜色、字号、间距、圆角、阴影、布局。就像房子的装修与配色。

⚡
JavaScript = 神经

决定“会做什么”：点击、展开、切换、计算、动画。就像房子里的开关与电路。

打个比方把网页想成一个人：HTML 是骨架（有哪些器官），CSS 是外貌与衣着（看起来什么样），JavaScript 是神经系统（能对外界作出反应）。三者缺一不可。

手写第一个 APEC 网页10 分钟 · 照着模板改

先别急着用 AI。亲手敲一次代码，你才会知道网页的骨架长什么样，以后也才看得懂 AI 写的代码。

APEC 知识网页 · 模板（把注释处换成你的内容）
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>APEC 知识网页</title>
  <style>
    body { font-family: "Microsoft YaHei"; margin: 20px; }
    h1 { color: #0284C7; }   /* 在这里修改标题颜色 */
    /* 在这里添加更多 CSS 样式 */
  </style>
</head>
<body>
  <h1><!-- 写你的页面标题 --></h1>
  <p><!-- 写一段 APEC 简介 --></p>
  <h2>成员经济体</h2>
  <ul>
    <li><!-- 写成员名称 --></li>
    <li><!-- 写成员名称 --></li>
  </ul>
  <h2>深圳与 APEC</h2>
  <p><!-- 写深圳与 APEC 的关系 --></p>
</body>
</html>
新建一个文本文件

命名为 index.html，注意扩展名是 .html 而不是 .txt。

把模板敲进去

手写一遍，别直接复制——敲的过程就是熟悉标签的过程。

用浏览器打开

双击文件，看看网页长什么样；改一个字，保存，刷新，再看看变化。

记录问题

哪里显示不对？哪里不知道怎么改？把问题记下来，下一步问 AI。

常见“翻车”点① 忘记写 <meta charset="UTF-8">，中文变成乱码；
② 标签忘了闭合，后面的内容全部“跑偏”；
③ 把文件存成了 .txt，浏览器打开只是一堆文字。

AI 编程：从描述到网页10 分钟 · 人机协作写代码

现在轮到 AI 上场了。用自然语言把需求说清楚，AI 就能生成完整的网页代码。关键在于：描述得越具体，代码越接近你要的效果。

AI 编程三步走
① 描述需求（Prompt）➜② 预览检查（浏览器）➜③ 迭代优化（改 Prompt）
基础版 · APEC 知识网页
请用 HTML 和 CSS 制作一个 APEC 知识科普网页，要求： 1. 页面标题「2026 APEC 深圳峰会」； 2. 第一部分：APEC 简介（100 字左右，介绍什么是 APEC）； 3. 第二部分：21 个成员经济体列表（用卡片式布局展示）； 4. 第三部分：深圳与 APEC（为什么选深圳、三大优先领域）； 5. 配色用蓝色系，现代简约风格，响应式布局； 6. 添加简单的 CSS 动画效果。
进阶版 · 加一个固定导航栏
在以上网页基础上，添加一个固定在页面顶部的导航栏，包含“APEC 简介”“成员经济体”“深圳与 APEC”三个链接，点击可平滑滚动到对应部分。导航栏背景半透明，滚动时添加阴影效果。
进阶版 · 嵌入数据图表
在网页中添加一个「APEC 数据可视化」板块，插入一张 APEC 经济体 GDP 对比柱状图（使用 <img src="gdp_chart.png" alt="APEC GDP 对比图">），图片下方添加一段 50 字的数据说明文字。
通用 · 让 AI 解释代码 / 修改样式
① 请帮我解释这段 HTML 代码每部分的作用，用初中生能懂的语言。 ② 请帮我把网页背景改成蓝色渐变（从 #E6F1FB 到 #B3D9F2），标题加大到 48px 并加粗居中，卡片加圆角和阴影效果。

AI 编程的优势与局限5 分钟 · 人还需要学编程吗？

✅ AI 编程帮了我们什么
  • 一键生成完整的代码框架，省下大量重复劳动
  • 看不懂的代码可以让它逐行解释
  • 改样式、加功能，用一句话就能实现
  • 把“想做”和“做出来”之间的门槛降到最低
⚠️ AI 编程的局限
  • 代码可能有错，需要人来运行、检查、修改
  • 不懂基础就看不懂它写了什么，也提不出好要求
  • 复杂需求需要多轮迭代，描述不清就一直改不对
  • AI 不了解你的真实想法和审美
讨论：如果 AI 能写代码了，人还要学编程吗？参考思路：学编程不只是学“打字打代码”，更是学把复杂问题拆成步骤的思维方式。懂原理，你才能判断 AI 写得对不对、才能提出更好的要求——这就像会算术的人，用计算器也更容易发现错误。

本课术语表

HTML

超文本标记语言，用标签描述网页的“骨架”——有哪些标题、段落、图片、列表。

CSS

层叠样式表，描述网页“长什么样”：颜色、字号、间距、圆角、布局。

JavaScript

网页的脚本语言，让页面“会动”：点击、展开、计算、动画。

标签（Tag）

HTML 里用尖括号表示的元素，如 <h1>、<p>、<img>，通常成对出现。

迭代调试

“描述需求 → 生成 / 编写 → 预览 → 发现问题 → 修改 → 再预览”的循环。

响应式布局

网页能根据屏幕大小自动调整排版，手机和电脑上都能正常浏览。
