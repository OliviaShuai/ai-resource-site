什么是智能体？与普通AI对话有什么区别？

智能体定义

智能体是能感知环境、自主决策、执行行动的AI系统。它比普通AI对话更专业、更专注，因为它有明确的角色、专属的知识和严格的规则。

生活中的智能体

  • Siri / 小爱同学：语音助手智能体
  • 淘宝客服机器人：智能客服智能体
  • 抖音推荐：推荐系统智能体

普通AI对话 vs 智能体 对比

对比维度 普通AI对话 智能体
角色 通用助手，没有特定身份 有明确角色设定（如APEC知识助手）
知识 依赖训练数据，可能过时或不准 有专属知识库，信息准确可控
规则 没有定制化的回答规则 有对话规则约束（长度、风格、安全边界）
专业度 回答可能笼统，可能跑题 回答专业、精准、聚焦特定领域
可控性 行为不可控，可能编造信息 规则约束行为，不确定时能诚实说"不知道"
一句话总结：智能体 = 普通 AI + 角色设定 + 知识库 + 对话规则。三要素缺一不可，让AI从"什么都能聊"变成"某个领域的专家"。

智能体三要素详解

类比：招聘一个APEC讲解员，你要告诉他三件事

三要素 招聘讲解员类比 在平台上的配置项 作用
角色设定 你是谁 角色Prompt输入框 决定"人格"和风格
知识库 你知道什么 知识库上传/文本输入 决定"能力边界"
对话规则 你怎么回答 规则/约束设置 决定"行为准则"

决定风格

B

关键理解：三要素不是独立的三块，而是配合工作的整体。角色决定"你是谁"，知识库决定"你能答什么"，规则决定"你怎么答"。三者共同决定了智能体的质量。

角色Prompt模板（可复制）

回忆第1课的"Prompt三要素：角色+任务+约束"——智能体的角色Prompt本质就是结构化的Prompt。下方模板可直接复制使用。

// ===== APEC知识助手 角色Prompt 模板 ===== 你是[智能体名称]，[身份描述]。 你的性格[性格特点]，像一个[类比角色]。 你了解[知识领域1]、[知识领域2]、[知识领域3]。 回答规则： 1. [规则1] 2. [规则2] 3. [规则3] 4. [规则4] 开场白：[友好问候，说明你的功能]
// ===== 完整示例：APEC小亚 ===== 你是小亚，2026年深圳APEC峰会的官方知识助手。 你的性格热情、专业、耐心，像一个博学的导游。 你了解APEC的基本信息（21个成员、成立时间、宗旨）、 2026年深圳APEC主题和三大优先领域、深圳为什么被选为举办城市。 回答规则： 1. 用初中生能听懂的语言回答 2. 回答控制在200字以内 3. 不确定的信息，诚实说"我还不确定这个信息" 4. 回答后主动问用户是否还有其他问题 开场白：你好！我是小亚，2026年深圳APEC峰会的知识助手。 想了解APEC什么都可以问我哦！
填写技巧：方括号 [...] 里的内容需要你替换成自己的。角色越具体，智能体"人格"越鲜明；规则越精确，智能体表现越好。
5
对话规则参考清单

编写规则时参考此清单。"好好回答"这种空话不算规则——规则要具体、能检查。

规则类别 规则示例（可直接抄用） 解决的问题
语言风格 用初中生能听懂的语言回答，避免过于专业的术语 回答太专业、看不懂
回答长度 回答控制在200字以内，重点突出 回答太长、没有重点
诚实性 不确定的信息，诚实说"我还不确定这个信息" AI编造信息 / 幻觉
互动性 每次回答后主动问用户是否还有其他问题 对话不连贯、不够友好
数据引用 回答数据问题时，附带说明数据来源 数据来源不明、可信度低
安全边界 不回答与APEC无关的问题，礼貌引导用户回到APEC话题 智能体偏离主题
格式规范 列举信息时使用序号或项目符号，让回答更清晰 回答格式混乱
选择建议：基础版至少选3条规则（推荐：语言风格 + 回答长度 + 诚实性）。进阶版选5条以上，加上数据引用和安全边界。

迭代优化方法指导

什么是迭代？

迭代 = 测试 → 发现问题 → 改规则 → 再测试 的循环。每转一圈，智能体更强一点。这是智能体开发的核心能力——系统设计思维。

为什么要迭代？

第一版智能体几乎不可能完美。规则越精确，智能体表现越好。只有通过测试发现问题、针对性修改，才能让智能体越来越好。

发布测试

2

→
3

改规则 or 补知识库

4

对比改善效果

测试问题推荐

测试问题 测试目的
"APEC有哪些成员？" 基础事实题：测试知识库是否完整
"2026年APEC在哪里举办？主题是什么？" 信息检索题：测试回答准确度
"中国香港是APEC成员吗？" 易混淆题：考验规则效果（是否诚实说不确定）
什么算"不满意"需要迭代？回答不准确 · 太长 · 语气不对 · 跑题 · 该说"不确定"却瞎编——都是要改的信号。发现问题别放过，那正是你下一次迭代的线索！

AI治理：从智能体规则到国家法律

核心类比：你给智能体定的规则 = AI治理的微观缩影

你给智能体定的规则 国家给AI公司定的法律 本质
不能胡说八道 不能生成虚假信息 约束AI的真实性
用初中生能懂的语言 考虑用户群体 约束AI的适用性
回答不超过200字 服务要有标准和边界 约束AI的行为范围

什么是AI治理？

约束AI的行为，让它安全、可靠、负责任地服务人类。你今天给智能体定规则，就是在做"微型AI治理"。

为什么需要国际合作？

AI是全球性技术。如果21个经济体的AI规则都不一样，同一个AI在不同国家行为不同，会造成混乱。APEC就是讨论AI规则的平台之一。

APEC成都数字与AI部长级会议

APEC 21个经济体一起讨论AI的发展和治理。这说明AI治理不是某一个国家的事，需要跨国合作。

治理的三大核心议题

安全：AI不能造成伤害
公平：AI不能有偏见
透明：AI的决策可解释

智能体平台操作指引

深教人工智能平台6 · AI 智能体模块 快速上手

本课统一使用 深教人工智能平台6 的「AI 智能体」模块创建 APEC 知识助手， 用学校统一账号登录。若课堂网络或账号暂时不可用，可改用备选平台 Coze（扣子）——下面的六个步骤在两种平台上完全一致。

  1. 登录：用老师提供的统一账号登录深教人工智能平台6，进入「AI 智能体」模块
  2. 新建智能体：点击"创建智能体"按钮 → 输入名称（如"APEC小助手"）→ 点击确认
  3. 设定角色：在角色设定（人设 / 提示词）区域填写角色 Prompt（参考第4节模板）
  4. 编写对话规则：把规则条目写进角色 Prompt 中（参考第5节清单）
  5. 配置知识库：进入"知识库"区域 → 点击"添加" → 可输入文本或上传文档（参考第9节APEC信息）
  6. 设置开场白：在"开场白"区域输入友好问候语
  7. 发布：点击"发布 / 保存"按钮 → 按提示确认
  8. 测试：在预览对话区输入测试问题，查看智能体回答
  9. 迭代：发现问题 → 回到配置页面修改 → 重新发布 → 再测试
  10. 保存链接：发布后获取智能体链接/二维码，务必保存好，第6课要用
遇到问题怎么办？
  • 登录不上？→ 举手找老师，使用共享账号
  • 发布失败？→ 检查角色Prompt是否完整，知识库是否配置
  • 智能体不按规则回答？→ 检查规则是否写在正确位置（角色Prompt中）
  • 知识库不生效？→ 确认知识库已上传成功并启用
  • 网络不通？→ 告诉老师，老师会用录屏演示替代

APEC基础知识速查（知识库素材）

以下信息可直接复制到智能体的知识库中，让你的APEC智能体"有料可答"。

APEC基本信息

  • 全称：亚太经济合作组织（Asia-Pacific Economic Cooperation）
  • 成立时间：1989年
  • 成员数量：21个成员经济体
  • 宗旨：推动区域经济一体化、贸易投资自由化
  • 运作方式：协商一致，非约束性

2026年深圳APEC

  • 举办城市：中国·深圳
  • 深圳特色：中国科技创新之都，被誉为"中国硅谷"
  • 主题：数字经济、可持续发展、包容性增长
  • 三大优先领域：贸易投资、数字经济、包容性可持续发展

APEC 21个成员经济体

澳大利亚、文莱、加拿大、智利、中国、中国香港、印度尼西亚、日本、韩国、马来西亚、墨西哥、新西兰、巴布亚新几内亚、秘鲁、菲律宾、俄罗斯、新加坡、中国台北、泰国、美国、越南。

注意：中国香港和中国台北是以经济体身份加入APEC的，不是以国家身份。这是一个常见的易混淆知识点——适合用来测试智能体的规则效果！

APEC成都数字与AI部长级会议

2024年7月，APEC在成都召开数字与AI部长级会议，21个经济体一起讨论AI的发展和治理。这说明AI治理已成为国际议题，需要跨国合作。

第3课数据（进阶知识库素材）

21个经济体的GDP、人口、贸易额等数据。如果你把这些数据输入知识库，智能体就能回答"APEC哪个经济体GDP最高？"等数据问题。

知识库配置技巧：基础版至少包含"APEC基本信息"和"2026年深圳APEC"两块内容。进阶版可以加入第3课的数据和成员经济体详细介绍。知识库越丰富，智能体能回答的问题越多！
